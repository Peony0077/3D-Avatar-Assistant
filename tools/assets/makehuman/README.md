# MakeHuman teeth and tongue (CC0)

`teeth_base.obj`, `teeth.png`, `tongue01.obj`, `tongue01_diffuse.png` come from the MakeHuman system assets
(https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html).
They were explicitly released under **CC0 1.0** in September 2020 by Data Collection AB, Joel Palmius and
Jonas Hauquier. `tools/blender/build_avatar.py` fits them into the Rocketbox avatar's mouth, replacing the
original low-poly painted teeth so open vowels show real teeth and a tongue.
